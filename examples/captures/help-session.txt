Create, resume, fork, import, or export saved sessions

Usage: zcode session <COMMAND>

Commands:
  create    Allocate a new session id
  continue  Continue a session. With a prompt it runs headless; without one it opens the TUI on that session
  fork      Branch a session into an independent copy
  import    Import a session JSON file under a fresh id
  export    Write a session transcript to a file
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

[exit 0]
